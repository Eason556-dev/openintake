# OpenIntake v0.7.2 — source preview / 源码预览版

## English

- Remove the separate meal confirmation checkbox. Tapping Record confirms actual intake after validation.
- Text with explicit g/mL quantities is organized without AI. Names and quantities can be saved locally even when all nutrients are unknown.
- Known nutrition values continue through the shared HealthKit outbox with permission checks, saved-sample verification, retry and undo.
- Include English/Chinese READMEs, simulator screenshots, a workflow diagram, self-build/device-install guides and a private signing example.
- Bundle identifiers and the Watch companion ID derive from one user-configurable prefix.

Download **OpenIntake-0.7.2-source.zip** and the matching **.sha256** from Assets. Extract, read README.md and open OpenIntake.xcodeproj. This is unsigned source, not an installable IPA. Use your own Apple signing team and identifiers.

Validation: 174 core tests passed, including unknown-only local meals and known-value HealthKit mock retry/undo behavior. See the repository validation notes for build results and device acceptance limits. This release is a developer preview; source compilation is not proof of true-device HealthKit acceptance.
