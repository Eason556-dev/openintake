# OpenIntake v0.8.0 — Offline nutrition and a clearer daily view

## English

- Native nutrition dashboard with energy, protein/carbohydrate/fat rings, essential nutrient and limit bars, all-nutrient details and trends. Shared identifiers keep iPhone and Watch projections consistent.
- Bundled USDA SR Legacy offline reference: 7,793 foods, indexed search, English/Chinese aliases, preparation selection and food-specific serving conversions. CC0 data with source version and archive checksum.
- Deterministic meal/nutrient text parsing, direct Energy entry, correct kcal/kJ and mg/g conversions, manual overrides and explicit unknown handling. No built-in AI, account or server required.
- Recover missing nutrient fields in older meal records through a reviewed edit. Keep the original event ID/time, retry safely, and avoid duplicate HealthKit samples. Unknowns and extract equivalents are never fabricated or added twice.
- Reusable meals for Watch quick logging, verified sample UUID tracking, consistent macro accents, and updated external checking prompt. Template zeros require confirmation or can be marked unknown together.
- Bilingual README with maintainer-supplied real-device views, a title icon and clear build/download guidance. Image metadata is stripped without changing the supplied UI pixels.

Validation: **219 core tests passed**; unsigned iOS Simulator/device and watchOS Simulator builds passed with Xcode 27.2. Publication/privacy and localization checks pass. GitHub Actions independently verifies the tagged source before creating assets.

This is an **unsigned source preview**, not an IPA or App Store installer. Build using your own eligible Apple team and device permissions. Food references are incomplete and do not identify every restaurant recipe or branded product. Chinese aliases cover a reviewed subset; unknowns remain unknown. Physical HealthKit acceptance and Watch background-delivery timing require device verification; screenshots and mock tests alone do not establish them.

Download `OpenIntake-0.8.0-source.zip` and its SHA-256 file from Assets. Follow [English build instructions](https://github.com/Eason556-dev/openintake/blob/v0.8.0/docs/BUILD.en.md) or the repository README.

## 简体中文

- 营养首页新增能量卡、三项宏量营养圆环、目标/限量进度、全部营养明细与趋势；iPhone、Watch 共用稳定的营养字段映射。
- 内置 USDA SR Legacy 7,793 项离线食品资料，提供索引搜索、中英文别名、生熟/做法选择与食品专属份量换算；记录来源版本与归档摘要。
- 餐食与营养汇总使用确定性解析；支持直接填写能量、kcal/kJ 和 mg/g 换算、手动总量调整，未知不填零。无需内置 AI、账号或服务器。
- 旧餐食可核对后补全遗漏字段并重新同步，保留原时间和事件 ID，支持失败重试与撤销，避免重复写入健康。
- 常用餐食可在 Watch 快速记录；保存核验后的 HealthKit 样本标识。更新外部核对 Prompt，模板零占位需核对或一键设为未知。
- 中英文 README 增加标题图标、实机展示及构建教程；展示图已清理隐私元数据，保留原始界面内容。

验证：**219 项核心测试通过**；Xcode 27.2 的 iOS 模拟器/设备无签名构建、watchOS 模拟器构建通过，隐私与语言检查通过。标签源码还会经过 GitHub Actions 独立验证再发布资产。

本版为**无签名源码预览版**，不是可直接安装的 IPA。请使用自己的合适 Apple 团队签名并进行设备授权。离线参考资料不覆盖所有品牌与菜谱，中文别名范围有限；真实健康写入和手表后台传输仍需按设备验收。
