# 0.7.1：语言显示与营养首页

完成日期：2026-11-01。版本 0.7.1 / build 18。

## 问题与修复

- 部分 View 直接显示核心模型的中文标题、成分映射说明与校验错误，绕过本地化；现在在显示边界翻译应用生成的内容。
- 动态提示缺少翻译，通知中的“开启／关闭”等插值也未本地化；已补齐对应键。
- 历史消息可能以之前的语言保存在事件中；`L10n.diagnostic` 识别已知模板，在显示时转换，保留插值参数，不改写事件。
- 成分列表原有独立语言偏好，可能覆盖 App 语言；移除该独立开关，标准化成分名称统一跟随 App 设置。
- 组件读取共享语言偏好，Watch 接收后刷新 locale。编辑页直接观察语言偏好，切换时不重建或清空草稿。
- 语言切换更新已存在的周期提醒文字，保留 identifier 与原触发计划；不额外申请权限或增加提醒。更新失败会明确提示重新保存。
- App Intents 执行对话跟随 App 语言，补齐系统动作元数据的翻译。系统权限弹窗和快捷指令编辑器仍由操作系统语言控制。

## 原文保护

不能删除代码中的所有中文：本地化键、中文 OCR 别名、测试输入和原始证据具有各自用途。

产品名称、包装原名、OCR 文字、用户输入及未识别成分不自动翻译。只有具有稳定身份的系统饮水/食盐模板、标准化成分和应用 UI 文案跟随语言切换。数量、内部标识、单位计算、产品版本、事件及 HealthKit 写入清单保持原有语义。

诊断模板转换仅用于应用生成的信息，禁止用于用户产品名或任意 OCR 内容。已有自定义文字或操作系统返回的错误可能使用原始语言；不使用模型翻译或网络服务。

## 首页布局

四个独立圆环改为单张今日营养卡片：能量、蛋白质、糖、钠采用对齐行，显示当前值、单位及已设置的目标/限量。

有已知数值和目标时显示紧凑进度条；未知保持 —，不画成零进度。糖、钠使用中性色，超出限量时提示，不以“摄入更多”作为奖励。补水页保留适合单一进度的圆环。卡片适配横向空间不足时的纵向排列。

## 验证与边界

- 170 项核心测试通过，新增覆盖动态消息双向语言切换、插值原文保护、全部营养标题、语言变化不改写产品与 HealthKit 计划。
- `scripts/check_localization.py` 检查字面量 L10n 键、占位符一致性及英文资源中残留中文，并接入 CI。本轮检查 506 处 UI 键调用、696 条英文资源，另核对构建生成的 App Intents 元数据，0 个缺失。该静态检查不是完整 Swift 语义分析，也不能证明所有系统界面都使用 App 内语言。
- iPhone、Watch、iPhone 组件与表盘组件无签名构建通过。模拟器构建及英文首页显示已检查；中英文首页截图仅为模拟器，不代表真实 HealthKit 写入。
- 真机仍需检查：编辑草稿时切换语言、重新进入各编辑/同步页面、通知文字更新、Watch/组件收到语言后的刷新、系统快捷指令编辑器与执行对话。
- 本轮不创建真实摄入，不改写历史健康样本。
